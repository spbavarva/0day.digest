SonicWall has warned of two vulnerabilities affecting end-of-life Global
Management System (GMS) software that it says will not be patched.
CVE-2026-109593 (CVSS 9.1) is an unauthenticated file read bug letting a
network-adjacent attacker read internal GMS files; a second flaw allows
database record alteration. Both affect GMS 9.5.2 and earlier.

Organizations still running the end-of-life platform should migrate off
it, since no fix is coming.
