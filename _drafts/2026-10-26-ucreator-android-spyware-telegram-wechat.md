A rentable Android spyware kit called uCreator hides malicious code inside
tampered copies of Telegram and WeChat to hijack accounts, including
stealing Telegram two-factor authentication codes.

The kit only reaches users who install one of the tampered app copies,
distributed outside official app stores, or who run WeChat inside the
kit's own container app. Researchers found the Telegram component shares
code with Baohuo, a previously documented backdoor. Users should install
messaging apps only from official stores.
