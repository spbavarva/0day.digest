CISA published an advisory for a path traversal vulnerability
(CVE-2026-107777, CVSS 6.5) in Thermo Fisher Torrent Suite Software versions
5.18 and earlier. Successful exploitation could allow an attacker to read
arbitrary files on the Torrent Server.

The product is used in healthcare and public health settings worldwide;
affected organizations should apply the vendor's fix or restrict network
access to the Torrent Server.
