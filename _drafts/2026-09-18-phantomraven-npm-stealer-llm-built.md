A financially motivated actor has been linked to PhantomRaven, a
JavaScript infostealer distributed through the npm package registry.
Researchers assess with high confidence that the malware was written
using an LLM, citing verbose comments, placeholder code, and
statistical token-analysis patterns as evidence.
