A financially motivated threat actor has been linked to PhantomRaven, a
JavaScript-based information stealer distributed via the npm registry.
Researchers assess with high confidence that the malware was written
using an LLM, citing verbose comments, placeholder code, and statistical
token-analysis patterns. The actor reportedly claims to be a bug bounty
hunter. This is a notable documented case of AI-assisted malware
development being identified through code-analysis artifacts.
