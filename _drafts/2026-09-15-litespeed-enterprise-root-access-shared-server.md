cPanel has warned of a critical vulnerability in LiteSpeed Web Server
Enterprise that could let a low-privilege website user gain root access
on a shared-hosting server.

On affected servers, many customers' sites run on a single machine, so an
attacker with just one of those hosting accounts could exploit the flaw
to access or alter other customers' sites, or compromise the server
itself. The advisory was published by cPanel on September 14.
