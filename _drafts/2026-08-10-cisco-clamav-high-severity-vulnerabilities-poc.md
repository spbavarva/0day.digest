Cisco disclosed high-severity vulnerabilities in ClamAV with public
proof-of-concept exploit code available, according to SecurityWeek. The
flaws could let remote, unauthenticated attackers cause a denial-of-service
condition. No CVE identifiers or affected version ranges were included in
the source summary. Organizations running ClamAV for mail or file scanning
should check for patched releases given the public PoC availability.
