Aikido Security disclosed eight high-severity flaws in the NodeBB forum
platform, found using AI pentest agents during a six-hour review of the
source code. The bugs allow admin-panel access and exposure of private
chats; proof-of-concept exploit code has been published.

Every version before 4.14.0 is affected. NodeBB has fixed all eight
flaws, and administrators should upgrade to 4.14.2 given the public PoC
availability.
