WatchGuard rolled out patches for a critical code injection vulnerability in
Fireware OS, part of a broader update addressing 15 bugs spanning code
execution, denial-of-service, authorization, and path traversal issues.

WatchGuard appliances are widely deployed as network security gateways,
making prompt patching important for internet-facing devices. No indication
of active exploitation was included in the advisory.
