Researchers flagged a malicious Visual Studio Code extension named
"Solidity Pro" (published under at least two publisher names, helper-beeps
and web3devtoolsx) that delivers a browser wallet and credential stealer,
according to The Hacker News. Neither extension remains available on Open
VSX, though the source GitHub repository was still noted as present.
Developers who installed Solidity Pro should treat any crypto wallets, API
keys, or credentials used on that machine as compromised and rotate them.
