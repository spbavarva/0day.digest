CISA added three flaws to its Known Exploited Vulnerabilities catalog on
August 5, 2026, citing evidence of active exploitation. The most severe is
CVE-2026-9198 (CVSS 9.8), a code injection vulnerability in Langflow that
allows unauthenticated attackers to achieve full remote code execution.

Flaws in Apache Tomcat and N-central were also added to the catalog.
Organizations running any of these products should patch immediately given
confirmed in-the-wild exploitation.
