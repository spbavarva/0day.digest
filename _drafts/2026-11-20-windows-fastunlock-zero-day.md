A researcher using the handles MSNightmare and Nightmare Eclipse disclosed
an unpatched Windows technique called FastUnlock that lets someone with
physical access to a locked PC start programs without signing in.

The technique only grants a limited user account, not administrator
control, and no patch is currently available. Endpoint security firm
ThreatLocker is tracking the issue.
