Kiteworks has released security updates addressing 126 vulnerabilities across
its secure file-sharing platform, including a max-severity code injection
flaw in its Email Protection Gateway (EPG) module. The available summary does
not specify a CVE identifier, the injection vector, or confirm active
exploitation. Organizations running Kiteworks EPG should prioritize patching
given the severity rating.
