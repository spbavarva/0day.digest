A developer's GitHub account, compromised several months earlier, was used to
push malicious code to unsuspecting downstream users in an OVHcloud-related
supply chain incident. Dark Reading ties the compromise to the GlassWorm
threat actor group.

The incident underscores how a single stale compromised credential can sit
dormant before being weaponized for a broader supply chain attack.
