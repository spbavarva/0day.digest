Hewlett Packard Enterprise released updates patching 72 vulnerabilities
in ArubaOS, the operating system for Aruba networking gear, including
eight maximum-severity flaws enabling authentication bypass and remote
code execution.

No evidence of active exploitation was cited at disclosure.
Organizations running Aruba controllers or switches should apply the
updates promptly, since auth-bypass and RCE flaws in network
infrastructure are high-value targets once details are public.
