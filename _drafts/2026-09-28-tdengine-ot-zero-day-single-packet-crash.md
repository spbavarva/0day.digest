A high-severity zero-day vulnerability lets a single network packet
crash servers running TDengine, a time-series database deployed across
industrial, IoT, energy, and automotive environments, according to Dark
Reading.

No CVE identifier, patch status, or technical exploitation details were
included in the available reporting. Organizations running TDengine in
OT or industrial contexts should watch for vendor guidance.
