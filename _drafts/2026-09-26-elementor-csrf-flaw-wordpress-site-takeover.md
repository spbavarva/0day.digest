A high-severity CSRF flaw in the Elementor Website Builder WordPress plugin
(CVSS 8.8) lets an unauthenticated attacker create rogue administrator
accounts and take over a site, if an admin clicks a crafted link.

The flaw has not yet been assigned a CVE identifier. It only affects
certain versions of the plugin; site owners should watch for a vendor
patch and update as soon as one ships.
