An analysis of Salesforce Agentforce describes how two standard,
independently documented features — Flow-triggered agent actions and
Email-to-Case/Web-to-Case intake — can combine to let external, untrusted
input reach an AI agent's prompt without the controls normally applied to
software changes.

Because each piece is "as designed," the resulting risk is easy to miss in
governance reviews built around traditional change control. Teams deploying
agent platforms should map out these feature chains explicitly rather than
reviewing each integration in isolation.
