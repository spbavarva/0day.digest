Microsoft has moved its Perception agentic security platform out of
preview, making four blue-team agents and a Recon Agent generally
available. Additional integrations and vulnerability shielding
capabilities remain in preview.

The platform is part of a broader push by major vendors to deploy
autonomous or semi-autonomous AI agents for defensive security tasks
like reconnaissance and blue-team operations, rather than purely
offensive or assistive use cases.

Security teams evaluating agentic AI tooling should note which
specific capabilities are GA versus still in preview before relying on
them in production workflows.
