Unit 42 researchers built a behavioral clustering model that maps cloud
identity roles from audit logs, aiming to help defenders spot anomalous
identity behavior across cloud environments.

The approach uses standard SQL queries against existing audit log data,
enabling continuous, low-overhead threat detection without deploying
additional agents.
