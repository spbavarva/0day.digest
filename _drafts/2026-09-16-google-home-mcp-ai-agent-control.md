Google launched early access to an MCP (Model Context Protocol) server
for Google Home, letting third-party AI agents such as Claude and
ChatGPT control connected smart home devices, review camera summaries,
and query smart home activity using natural language.

The integration standardizes how outside AI agents can access and act
on connected devices. Granting broad natural-language device control to
third-party agents introduces a new access-control surface for smart
home security that has not yet been publicly assessed.
