A new tool called XRanges scores autonomous security agents by
verifying their self-reported findings against a target, addressing
a gap where agent-generated vulnerability reports can't otherwise be
checked for accuracy. The approach was validated using results from
545 human hackers before being applied to AI agent output.

The tool addresses a practical problem in agentic pentesting: agents
can produce confident-sounding reports that require manual
verification, and XRanges aims to automate that verification step.
