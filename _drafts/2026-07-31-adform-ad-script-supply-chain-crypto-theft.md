Online advertising firm Adform suffered a supply-chain attack in which its
script was modified to deliver cryptocurrency-stealing code to websites
using its ad platform.

The injected script replaced cryptocurrency wallet addresses copied to
victims' clipboards with attacker-controlled addresses, a technique known
as clipboard hijacking. Because the compromise sits in a widely embedded
third-party ad script, any site loading Adform's tag could have served the
malicious code to visitors.
