Vulnerable Check Point Security Gateway instances have been targeted in
attacks using a technique dubbed PHP2Shell to gain code execution, according
to BleepingComputer. Once inside, attackers deployed data-wiping malware
against connected VMware ESXi hosts.

No patch or exploitation-timeline detail was disclosed beyond the attack
chain itself. Organizations running Check Point Security Gateway should
review exposure and check ESXi hosts reachable from affected gateways for
signs of compromise.
