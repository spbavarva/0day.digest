A threat actor is advertising employee databases allegedly stolen from
Microsoft Azure infrastructure belonging to multiple Fortune 500 companies,
claiming the access was gained using compromised credentials. The claim
covers roughly 3.6 million account records and has not been independently
verified by Microsoft or the affected companies. If confirmed, the scale and
credential-based access vector would make this a significant enterprise
cloud security incident worth monitoring for further disclosure.
