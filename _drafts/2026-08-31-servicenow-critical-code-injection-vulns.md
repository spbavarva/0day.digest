ServiceNow has patched three critical code injection vulnerabilities in its
platform. Successful exploitation could let an attacker execute arbitrary
code or access and tamper with customer data. No CVE identifiers or
confirmation of active exploitation were included in the disclosure.
Customers should apply the vendor's patches and review instance logs for
anomalous activity.
