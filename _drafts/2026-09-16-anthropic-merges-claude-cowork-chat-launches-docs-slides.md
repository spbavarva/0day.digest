Anthropic is merging Claude's chat and Cowork interfaces into a single
unified "Claude" experience, rolling out first to Pro and Max
subscribers on web, desktop, and mobile. Alongside the merge, Anthropic
launched Docs and Slides, letting users create documents and
presentations directly from Claude chats that can be exported, edited,
and shared.

The changes consolidate what had been separate chat and Cowork surfaces
into one general-purpose agent interface.
