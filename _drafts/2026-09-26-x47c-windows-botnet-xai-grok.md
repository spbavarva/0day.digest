A newly identified Windows botnet, dubbed x47.c, uses xAI's Grok model to
maintain persistence on infected machines, querying the model to choose
from a set of predefined actions rather than relying on hardcoded logic.

The operation is also reported to involve draining AI API access as part
of the campaign.
