Microsoft closed a flaw in Azure API Management that attackers
exploited to target secrets held by Norwegian energy companies
Equinor and Skagerak Energi, with other sectors reportedly affected
too.

Norway's cybersecurity authorities confirmed both companies were hit.
Organizations using Azure API Management for service-to-service
authentication should review Microsoft's advisory and rotate any
potentially exposed secrets.
