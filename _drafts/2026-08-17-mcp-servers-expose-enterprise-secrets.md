Model Context Protocol (MCP) servers, which let AI agents reach enterprise
tools and data, can expose secrets through plaintext configuration files,
over-permissioned access, and prompt injection. This exposure can happen
silently, often before a security team even knows an MCP server is running.

As organizations adopt AI agents more broadly, unmanaged MCP servers are
becoming a growing gap in enterprise security posture.
