Google Cloud introduced IAM Helper, a set of agent-facing Agent Skills and
MCP tools meant to automate identity and access management workflows for
organizations deploying autonomous agents.

The goal is to reduce the security friction that builds up when agents
provision cloud resources, write Terraform, or deploy microservices faster
than CI/CD pipelines can safely authorize.
