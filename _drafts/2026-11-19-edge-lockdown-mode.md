Microsoft is developing a new Edge browser security feature called
Lockdown Mode that reduces attack surface by disabling the WebGL,
WebGL2, and WebGPU APIs. GPU-exposed browser APIs have been a recurring
source of exploitation primitives. The feature is currently in testing
and not yet broadly available, with no general-availability timeline
given.
