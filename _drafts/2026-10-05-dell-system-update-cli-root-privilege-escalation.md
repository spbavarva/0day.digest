Dell is urging customers to patch a critical vulnerability in its
System Update (DSU) command-line deployment tool that lets an attacker
escalate to root privileges. Dell's advisory characterizes the flaw as
critical and recommends immediate patching. No CVE identifier or
exploitation detail was included in the available summary.
Organizations using DSU for fleet management should prioritize applying
Dell's fix.
