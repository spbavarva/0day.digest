Fortra has patched multiple vulnerabilities in BoKS, its privileged access
management product. The flaws could allow authentication bypass, arbitrary
shell command execution, and memory corruption.

No details yet on affected version ranges or whether exploitation has been
observed in the wild. Organizations running BoKS should apply Fortra's
patches.
