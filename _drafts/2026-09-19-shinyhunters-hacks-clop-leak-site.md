The ShinyHunters extortion group breached the Tor-based data leak site run by the Clop (Cl0p) ransomware operation, defacing the site in the process.

ShinyHunters claims to have stolen server data along with the private keys for Clop's onion service, and is reportedly threatening to extort the ransomware gang using the stolen material — an unusual case of rival threat actors targeting each other.
