Source code for the Flying Eagle Android remote access trojan (RAT)
framework is circulating through criminal Telegram channels. Researchers at
Hunt.io and independent researcher NetAskari traced matching control panels
and certificates to roughly 170 internet-facing servers. The framework has
been linked to a fake Chinese public-security app ("公安一网通办") used to
target Android users in China, with capabilities including
payment-password theft. Wider reuse by other actors is likely now that the
source is public.
