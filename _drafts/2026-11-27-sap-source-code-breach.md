German software giant SAP has confirmed a cybersecurity incident following
reports that attackers infiltrated its software development infrastructure.
The reports indicate the intrusion may have given attackers access to
SAP's source code via GitHub.

SAP has not disclosed the full scope of systems affected or confirmed what,
if any, source code was accessed. Given SAP software's widespread
enterprise deployment, a confirmed source code compromise would raise
supply chain risk concerns for customers running affected products.
