Microsoft reminded customers that the Entra ID authentication system will
gain stronger protection against external script injection attacks starting
next month, closing off a class of attacks that inject malicious scripts into
the authentication flow.

Organizations relying on Entra ID for identity should review the announced
change ahead of the rollout to confirm it doesn't break any custom
authentication customizations that depend on current behavior.
