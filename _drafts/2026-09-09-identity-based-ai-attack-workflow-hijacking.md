A technique dubbed "workflow identity hijacking" can bypass standard
security controls and hijack an organization's data by sending a basic
request through an unauthenticated entry point. The technique targets the
nonhuman identities AI workflows and agents use to access enterprise
systems, an area many identity security controls don't yet cover.
