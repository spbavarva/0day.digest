The maintainer of BTCPay Server, an open-source cryptocurrency payment
processor, is warning that attackers have been draining "hot wallets" on
instances running outdated versions of the software.

Users are urged to update to the latest release immediately. No CVE or
technical exploit detail has been published alongside the advisory, so the
exact mechanism attackers use to drain wallets is unconfirmed.
