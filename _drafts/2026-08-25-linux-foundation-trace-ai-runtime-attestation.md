TRACE is a new open standard for AI runtime attestation, contributed to the
Linux Foundation by AMD, Intel, Microsoft, OPAQUE, and TII. Runtime
attestation lets a system cryptographically prove what code and
configuration are actually running before it processes sensitive workloads,
which matters for confidential-computing style guarantees around AI
inference. Moving governance to the Linux Foundation is meant to give the
standard a vendor-neutral home rather than leaving it controlled by any one
contributor. No implementation timeline or adopting products were included
in the available summary.
