Gen Digital reports that China-linked group UNC3569 exploited a flaw in
Sogou Input Method, a widely used Chinese-character input tool for
Windows, to install the GRAYRABBIT backdoor. The attack starts with a
crafted link and ends with the attacker able to perform any action
available to the logged-in user. Tencent owns Sogou; patch availability
was not detailed in the summary.
