ANY.RUN researchers detailed Skyw4lker, a device code phishing campaign
primarily targeting American organizations.

Rather than stealing credentials directly, the technique abuses legitimate
cloud services, authentication mechanisms, and trusted business workflows to
gain account access while leaving fewer obvious signs behind for defenders
to spot.

Security teams should review how device code and similar non-interactive
authentication flows are monitored, since this class of attack is designed
to blend into normal cloud sign-in activity.
