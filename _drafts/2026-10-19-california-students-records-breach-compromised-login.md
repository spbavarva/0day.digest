Intruders used a single set of compromised credentials to access an ETS
SFTP server, copying records for millions of California students dating
back to 2006.

The incident shows how one credential compromise on a third-party data
transfer server can expose decades of accumulated student PII.
Organizations using SFTP for bulk data transfer should enforce MFA and
limit standing access to such servers.
