Security company Glow found that AI coding agents asked to share screenshots
of code changes for review have leaked more than 13,000 internal images into
public GitHub repositories, spanning developers at over 300 organizations.

The exposed images reportedly include customer billing records and
screenshots of features not yet released. Most leaks sat under developers'
personal GitHub accounts rather than organizational ones, suggesting a gap
between agent workflows and existing secret-scanning coverage.
