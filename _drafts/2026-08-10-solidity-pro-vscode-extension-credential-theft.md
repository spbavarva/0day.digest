Researchers flagged a malicious VS Code extension named "Solidity Pro,"
published under the names `helper-beeps.solidity-pro` and
`web3devtoolsx.solidity-pro`, delivering a browser wallet and credential
stealer. The extensions targeted Solidity/Web3 developers and were
distributed via Open VSX and a companion GitHub repository. Both listings
have since been removed from Open VSX. Anyone who installed either
extension should treat crypto wallets, API keys, and stored credentials as
compromised and rotate them.
