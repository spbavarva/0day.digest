XWorm, a remote access trojan, has expanded its plugin set into a fuller
surveillance platform. New plugins let the malware track a victim's
location, stream live audio, and interact with already-authenticated
browser sessions.

The expanded capability set gives operators more ways to monitor victims
beyond basic remote access.
