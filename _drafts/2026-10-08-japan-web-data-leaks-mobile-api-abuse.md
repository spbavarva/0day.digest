JPCERT/CC says attackers behind a string of recent personal data leaks
at Japanese organizations have been abusing mobile app APIs and
exploiting known software flaws, including attacks on Metabase
instances.

The October 8 alert is based on incident reports JPCERT/CC has received;
it does not name a specific attacker or affected organization.
