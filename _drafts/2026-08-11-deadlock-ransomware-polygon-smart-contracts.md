The DeadLock ransomware group has been observed using decentralized
infrastructure to run its victim communications and data-leak operations.
According to Microsoft Threat Intelligence, the group's recovery ecosystem
combines the Session messaging network with blockchain-backed services on
Polygon to store and deliver extortion materials, making the
infrastructure more resilient to takedown efforts.
