An AI-powered attack exploited multiple zero-day vulnerabilities in Zammad,
the open-source helpdesk platform used by DIVD (Dutch Institute for
Vulnerability Disclosure), chaining the flaws to hijack sessions, achieve
remote code execution, and escalate privileges to root. The available
summary does not include CVE identifiers, attacker attribution, or affected
version ranges. Organizations running Zammad should watch for an official
advisory and apply patches once available.
