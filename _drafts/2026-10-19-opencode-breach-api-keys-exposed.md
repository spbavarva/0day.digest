OpenCode, a popular open-source AI coding agent and alternative to Claude
Code and Cursor, disclosed that attackers breached part of its online
platform and stole API keys that a small number of users had used with
external AI providers. OpenCode has notified the affected users.

Reporting on the incident also noted that AI tools consulted during the
investigation refused to analyze the malicious code involved. Affected
users should rotate any API keys they used with OpenCode immediately.
