Source code for the Flying Eagle Android remote access trojan framework is
circulating on criminal Telegram channels, according to Hunt.io and
independent researcher NetAskari. The researchers traced matching control
panels and certificates to roughly 170 internet-facing servers. The
framework has been linked to a fake Chinese public security service app
("公安一网通办") targeting Android users, with capabilities including
payment-password theft. Because the source is now circulating, defenders
should expect variant activity as other actors adopt the leaked kit.
