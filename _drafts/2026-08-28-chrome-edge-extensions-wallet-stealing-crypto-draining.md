Security researchers at Socket identified 19 browser extensions, 18 for
Chrome and one for Microsoft Edge, published over the past six months that
contain wallet secret-stealing and cryptocurrency-draining code. Researcher
Karlo Zanki said the extensions share code and tradecraft similarities,
indicating a coordinated campaign that has likely been active for some
time. Users who installed crypto-related browser extensions recently should
review installed extensions, remove anything unfamiliar, and rotate wallet
credentials if compromise is suspected.
