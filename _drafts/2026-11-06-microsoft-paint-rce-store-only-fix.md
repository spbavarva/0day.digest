A fix for CVE-2026-83844, a remote code execution flaw in Windows
Paint caused by an out-of-bounds read, is now available — but only
through the Microsoft Store, not through Windows Update. The fixed
build is 11.2609.401.0.

Users and admins relying on Windows Update alone will not receive this
fix automatically and should check the Store directly.
