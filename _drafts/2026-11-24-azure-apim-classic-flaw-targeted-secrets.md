Norway's National Security Authority (NSM) disclosed a vulnerability in
Microsoft Azure API Management (APIM) that an unknown actor exploited to
search for access tokens, secrets, and named values across multiple
Norwegian businesses, including energy companies Equinor and Skagerak
Energi.

Microsoft has fixed the underlying flaw. It remains unclear how the actor
identified the affected organizations.
