Google warned that attackers are increasingly hijacking enterprise
access to large language models, a technique dubbed LLMjacking, to
fraudulently run up cloud compute charges. Some organizations have
lost more than $100,000 per day, with total losses reaching roughly
$1 million for certain victims.

Attackers typically obtain API keys through phishing, source code
leaks, misconfigured environments, or exposed client-side code.
Organizations should audit LLM API key exposure and monitor for
anomalous usage spikes.
