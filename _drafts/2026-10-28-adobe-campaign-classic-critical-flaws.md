Adobe patched eight critical flaws in Campaign Classic, including a code
injection bug tracked as CVE-2026-104351 (CVSS 9.9) that can lead to
arbitrary code execution. The remaining seven flaws can be chained for
security feature bypass and privilege escalation. No active exploitation
has been reported. Organizations running Campaign Classic should apply
Adobe's patches immediately.
