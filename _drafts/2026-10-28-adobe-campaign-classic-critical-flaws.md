Adobe patched eight critical vulnerabilities in Campaign Classic that could
allow arbitrary code execution, security feature bypass, and privilege
escalation.

The most severe, CVE-2026-104351, is a code injection flaw rated CVSS 9.9
that can lead to arbitrary code execution.

No active exploitation has been reported. Campaign Classic customers should
apply Adobe's patches as soon as possible given the severity of the flaws.
