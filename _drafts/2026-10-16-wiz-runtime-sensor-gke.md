Google Cloud and Wiz have introduced a Runtime Sensor add-on for Google
Kubernetes Engine (GKE), now in preview.

The integration provides low-touch deployment, automated lifecycle
management, enterprise credential security, and fleet-wide governance for
Wiz's runtime threat detection on GKE clusters.

It is aimed at catching active attacks in real time, rather than relying
solely on at-rest vulnerability scans.
