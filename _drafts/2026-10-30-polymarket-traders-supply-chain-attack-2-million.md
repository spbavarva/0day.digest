Attackers drained more than $2 million from Polymarket traders using
malicious code linked to a third-party website monitoring tool, according
to SecurityWeek.

The injected code was designed to hijack active, logged-in Polymarket
sessions and siphon funds directly from affected accounts.

This is a supply chain attack: the monitoring tool itself, not Polymarket's
own code, was the entry point for the malicious script.

Sites that embed third-party monitoring or analytics scripts should be
aware that a compromised vendor script can be used to attack any site that
loads it, not just the vendor's own customers.
