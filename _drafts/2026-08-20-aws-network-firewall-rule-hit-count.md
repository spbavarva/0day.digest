AWS Network Firewall now supports rule hit counts, giving security teams
visibility into which firewall rules are actively matching traffic versus
which are dormant. Previously, teams had to rely on manual log analysis to
determine this, creating operational and compliance gaps — particularly for
organizations with policies requiring removal of unused rules. The feature
is available now for AWS Network Firewall customers.
