Anthropic is rolling out shared memory across Claude's chat and Cowork
surfaces, so users no longer have to re-brief the AI on ongoing projects,
preferences, or other context in every new session.

The change brings Claude's memory handling closer to persistent-context
approaches other AI assistants have already shipped.
