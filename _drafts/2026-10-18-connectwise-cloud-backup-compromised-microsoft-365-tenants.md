ConnectWise has disabled seven ConnectWise Cloud Backup application
identities after unknown threat actors obtained unauthorized access to them
and used that access to compromise customer Microsoft 365 tenants.

The company has suspended the Cloud Backup service while it investigates.
Organizations that use ConnectWise Cloud Backup should review Microsoft 365
tenant activity for signs of unauthorized access tied to the disabled
identities.
