The threat actor behind the GhostAction supply chain attack has expanded
beyond injecting malicious GitHub Actions workflows into compromised
projects to phishing open-source developers directly, delivering stealer
malware disguised as a font file across 94 GitHub repositories.

The shift, detailed by OpenSourceMalware, suggests the group is actively
adapting its tactics in response to defensive countermeasures. Developers
should treat unexpected font-file attachments or dependencies tied to
GitHub-hosted projects with suspicion.
