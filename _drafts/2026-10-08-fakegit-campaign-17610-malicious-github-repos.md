The FakeGit campaign has reactivated, flooding GitHub with more than
17,610 fake repositories distributing the SmartLoader malware loader.

SmartLoader is being used to push the StealC infostealer onto victims
who clone or download code from the malicious repos. Developers should
verify repo provenance and commit history before pulling code from
unfamiliar GitHub projects.
