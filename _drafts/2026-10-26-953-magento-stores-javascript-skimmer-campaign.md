An unknown threat actor has infected 953 online stores, most of them running
Magento, in a campaign that Dutch e-commerce security firm Sansec says has
been active since July 2025.

The injected code is a small loader added to store pages that, when visited,
serves a malicious JavaScript payload to shoppers or does nothing at all —
a design apparently meant to evade security scanners that check pages only
once.
