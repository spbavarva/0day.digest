Researchers discovered 13 malicious NuGet packages used as part of a fake
recruitment campaign.

The campaign targets .NET developers with poisoned job assessments that
spread malware and give attackers access to victims' machines.

Developers should treat take-home coding assessments from unfamiliar
recruiters as untrusted code and review any bundled NuGet dependencies
before running them.
