Threat actors are distributing malicious loaders and cryptocurrency miners
disguised as desktop apps for Claude and ChatGPT, in a campaign dubbed
"Yoba." The operation sets up fake GitHub projects claiming to be apps such
as "GPT-5.6 Sol" and "Claude Opus," using signed executables to help evade
detection before dropping the miner payload.

Users should only install AI desktop tools from official vendor sources, not
third-party GitHub projects claiming to package them.
