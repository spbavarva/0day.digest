Cisco has disclosed five critical vulnerabilities in its NX-OS data
center network operating system that could let an attacker run
arbitrary code with root privileges on Nexus switches.

Data center operators running Nexus switches on NX-OS should prioritize
patching given the root-level code execution impact.
