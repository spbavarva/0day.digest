OpenAI expanded its Codex coding agent with reusable cloud development
environments that persist across devices, a revamped CLI with voice
controls, and new code review tools. The update also includes a new
security-focused product for scanning repositories and preparing fixes.
Further technical specifics on the scanning tool's detection coverage were
not detailed in initial reporting. This positions Codex more directly as an
AppSec-adjacent tool rather than purely a coding assistant.
