Microsoft is testing a new feature that lets enterprise IT administrators
remotely lock lost or stolen Windows devices without wiping them. This
gives organizations a middle option between leaving a missing device
untouched and triggering a full remote wipe, preserving data recovery
options if the device is found.

The feature is still in testing and not yet broadly available. IT teams
managing fleets of Windows endpoints may want to track its rollout as an
addition to existing device-loss response options.
