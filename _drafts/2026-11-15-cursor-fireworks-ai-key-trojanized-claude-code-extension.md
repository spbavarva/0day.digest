The compromise of Anthropic's official Claude Code extension on Cursor's
extension marketplace traces back to a stolen access key, Cursor said in a
Friday update. The key had been issued to Fireworks AI and was exposed in a
breach targeting that company.

An attacker used the stolen key to copy data from a read-only resource and
leveraged the access to push a trojanized version of the Claude Code
extension to Cursor's marketplace, affecting users who installed or updated
it from that channel. The incident highlights third-party key exposure as a
growing supply-chain risk for AI coding tool marketplaces.
