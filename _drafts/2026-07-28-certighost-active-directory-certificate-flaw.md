Microsoft patched a high-severity vulnerability, dubbed "Certighost" by
researchers, in Active Directory Certificate Services. The flaw allows a
threat actor to escalate privileges and compromise an AD environment. The
fix shipped earlier this month; organizations running AD CS should confirm
the update is applied given the scope of privilege escalation it enables.
