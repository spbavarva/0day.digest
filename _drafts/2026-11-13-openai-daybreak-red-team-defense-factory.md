OpenAI introduced two security tools: Daybreak Red Team, which uses AI
agents to pentest web applications, and Defense Factory, which investigates
security findings and helps prepare patches.

Organizations evaluating AI-driven pentesting or patch-automation tools
should review how findings are validated before being acted on
automatically.
