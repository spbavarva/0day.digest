Adobe released updates for Campaign Classic (ACC), its enterprise marketing
automation platform, fixing CVE-2026-48449 — a maximum-severity flaw scoring
10.0 on CVSS.

The bug stems from incorrect authorization and could allow arbitrary code
execution without user interaction. No active exploitation was reported at
disclosure. Organizations running Campaign Classic should apply Adobe's
update promptly given the unauthenticated attack path.
