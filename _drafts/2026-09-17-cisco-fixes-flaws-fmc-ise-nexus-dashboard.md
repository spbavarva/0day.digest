Cisco patched a batch of vulnerabilities spanning Firepower Management
Center (FMC), Identity Services Engine (ISE), and Nexus Dashboard.
Depending on the specific flaw, exploitation could lead to root access,
arbitrary command execution, security bypasses, SQL injection, or remote
code execution.

This is a separate patch batch from the actively exploited ISE zero-day
(CVE-2026-76460) disclosed the same week. Organizations running any of
these three products should prioritize patching given the range of
impacts across the batch.
