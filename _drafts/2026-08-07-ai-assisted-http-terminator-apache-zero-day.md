PortSwigger says HTTP Terminator, an AI-assisted research system built by
James Kettle, generated and proved new HTTP desynchronization techniques
after exploring roughly 30,000 candidate desync vectors. A separate,
human-guided discovery effort using the same research also uncovered a
zero-day in Apache Traffic Server. The available summary does not include
further technical detail on the Apache flaw.
