Vulnerabilities in The Events Calendar, a WordPress plugin, allow
unauthenticated attackers to achieve remote code execution, according
to SecurityWeek. The plugin is used on more than 200,000 WordPress
sites, meaning unpatched installs are exposed to full site takeover.

Site owners running The Events Calendar should update to the patched
version immediately.
