Google has expanded its Cloud Vulnerability Reward Program with a new
top-tier $250,000 reward for high-impact architectural security flaws
that lead to root-level compromise in Google Cloud ("Root-in-Cloud"
bugs), according to BleepingComputer. The move targets researchers
hunting for the most severe class of cloud infrastructure
vulnerabilities.
