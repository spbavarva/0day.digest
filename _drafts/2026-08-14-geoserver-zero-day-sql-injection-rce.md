Attackers are actively exploiting an unpatched zero-day vulnerability in
GeoServer, an open-source geospatial data server. The flaw is described as a
SQL injection issue that can be leveraged to achieve remote code execution.

No patch is currently available. Organizations running GeoServer should
assess their exposure and apply any vendor-recommended mitigations while a
fix is pending.
