SolarWinds released security updates for CVE-2026-28326 (CVSS 8.8), a hard-coded key vulnerability in Access Rights Manager (ARM) that could allow unauthenticated remote code execution.

The flaw affects all versions of ARM 2026.2 and prior. Organizations running ARM should apply the vendor's patch as soon as possible.
