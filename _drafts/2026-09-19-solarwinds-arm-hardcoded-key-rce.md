SolarWinds released security updates fixing a high-severity flaw in
Access Rights Manager (ARM), tracked as CVE-2026-28326 and rated 8.8
on the CVSS scale. If exploited, the hard-coded key issue could enable
unauthenticated remote code execution.

The flaw affects all versions of ARM 2026.2 and prior. Organizations
running ARM should apply the patch as soon as possible.
