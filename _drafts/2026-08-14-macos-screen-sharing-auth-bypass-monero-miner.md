The Netherlands' National Cyber Security Centre (NCSC) is warning that
attackers are actively exploiting a macOS Screen Sharing authentication
bypass vulnerability. Public exploit code for the flaw has already surfaced,
lowering the bar for opportunistic attackers.

Observed attacks use the bypass to gain access to macOS systems and deploy a
Monero cryptocurrency miner. Organizations running exposed macOS Screen
Sharing services should treat this as an active threat and restrict access
to the service where possible.
