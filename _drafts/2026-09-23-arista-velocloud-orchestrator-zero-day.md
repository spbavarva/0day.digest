Arista Networks has released security patches for a zero-day flaw
that is being actively exploited and affects VeloCloud Orchestrator
(VCO) On-Prem deployments. Arista is urging customers to patch
immediately.

A CVE identifier and further technical exploitation details were not
included in the source summary. Organizations running VCO On-Prem
should apply Arista's patch without delay given confirmed active
exploitation.
