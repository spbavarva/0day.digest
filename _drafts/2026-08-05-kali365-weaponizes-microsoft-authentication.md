A phishing kit dubbed Kali365 is targeting US organizations by abusing
Microsoft's device code authentication flow. Victims are tricked into
approving an attacker-controlled device code on Microsoft's genuine login
page.

Once access and refresh tokens are issued, attackers can retain access to
email, documents, and cloud resources — creating a path to data exposure
and financial fraud without ever touching a fake login page. Enterprises
should monitor for anomalous device code sign-ins and consider restricting
the device code flow where it isn't needed.
