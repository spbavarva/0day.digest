Apple shipped security updates for macOS and iOS patching dozens of WebKit
vulnerabilities. The bugs could be exploited to crash Safari, corrupt memory,
leak sensitive data, escape the sandbox, and exfiltrate data. No active
exploitation was noted in the disclosure. Given WebKit's broad attack surface
across Safari and in-app web views, users should apply the updates promptly.
