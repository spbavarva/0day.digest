Radware disclosed that attackers gained access to some customers' account
details and cloud access keys after compromising an internal Cloud WAF
management API that had been left exposed on the open internet. The company
hasn't disclosed how many customers were affected.

Organizations using Radware's Cloud WAF should rotate any cloud access keys
and credentials tied to their account as a precaution.
