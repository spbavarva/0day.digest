Truffle Security has launched a free Secrets Revocation Program to help API
key issuers revoke roughly 1.4 million publicly exposed secrets that remain
valid. The initiative targets live credentials found exposed in public
repositories and other sources, working with issuers to revoke them at
scale.

Teams that scan for leaked secrets should check whether their key issuers
participate in the program as an additional remediation channel.
