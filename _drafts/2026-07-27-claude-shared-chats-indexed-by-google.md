Some Claude conversations and Artifacts shared via Anthropic's "share
chat" link feature have been indexed by Google Search, making them
discoverable to anyone searching relevant terms rather than only people
holding the link. The source summary does not specify how many shared
links were affected or whether Anthropic has changed default indexing
behavior.
