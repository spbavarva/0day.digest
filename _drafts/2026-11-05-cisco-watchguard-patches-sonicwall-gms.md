Cisco patched a remote code execution vulnerability in UCS Central
Software. WatchGuard separately fixed authentication-bypass and
man-in-the-middle flaws in its Fireware software.

SonicWall reiterated that it will not patch flaws affecting its end-of-life
Global Management System software, consistent with its earlier
end-of-life announcement. Organizations still running Cisco UCS Central or
WatchGuard Fireware should apply the new patches; GMS users should plan
migration off the platform.
