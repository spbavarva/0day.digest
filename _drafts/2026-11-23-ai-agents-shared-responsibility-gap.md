AI agents increasingly operate across multiple platforms and vendors,
creating security gaps where no single party can see or control the
full scope of an agent's actions, according to analysis from Token
Security.

The piece frames this as a shared-responsibility problem, similar to
cloud security, but applied to non-human agent identities and their
permissions. Teams deploying AI agents should inventory agent
identities the same way they inventory service accounts.
