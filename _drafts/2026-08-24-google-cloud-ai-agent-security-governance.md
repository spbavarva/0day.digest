Google Cloud's new State of AI Infrastructure report finds that 79% of
tech leaders cite security, governance, or operations as their most
significant challenge to scaling AI inference.

The report frames autonomous agents as "the ultimate insiders" — systems
granted permission to read emails, query databases, and trigger API calls
on their own. Google argues this shifts the threat model: traditional
security tools still matter, but agent-specific governance is now a
core requirement rather than an afterthought.
