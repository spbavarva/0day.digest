Kiteworks has released security updates addressing 126 vulnerabilities,
including a max-severity code injection flaw in its Email Protection
Gateway (EPG).

Kiteworks EPG is used by organizations for secure file sharing and email
protection, making it a sensitive target for exploitation.

Customers running Kiteworks EPG should apply the available patches as soon
as possible given the severity of the flaw.
