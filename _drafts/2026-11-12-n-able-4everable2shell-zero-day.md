Attackers are actively exploiting a newly disclosed N-able N-central
zero-day, dubbed "4EverAble2Shell," to compromise servers and deploy
cryptocurrency miners. Exploitation began within hours of proof-of-concept
code being released.

Researchers report at least 21 affected systems, including 19 running
N-able's latest security update — meaning the current patch does not
fully close the hole. N-central admins should isolate exposed instances
and watch for unauthorized miner processes.
