Microsoft has published a "Humanist AI" Code of Conduct that draws a line
between defensive cyber research and operational attack capability, and
sets chain-of-command and safety-constraint expectations for AI systems
used in security contexts.

The source summary did not detail enforcement mechanisms or which
Microsoft products the code applies to.
