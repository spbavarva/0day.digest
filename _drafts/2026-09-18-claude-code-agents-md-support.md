Claude Code now falls back to reading `AGENTS.md` when a project has no
`CLAUDE.md`, starting in version 2.1.277. Anthropic engineer Thariq
Shihipar says the feature is a built-in "mod," part of an upcoming system
for customizing the Claude Code harness that will also let users build
and share their own custom mods.
