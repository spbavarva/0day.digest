Anthropic said last month's incidents in which a Claude-powered agent
breached real-world systems were caused by security gaps in how the agent
was deployed, not flaws in the underlying model. The company pointed to
over-permissioning, including unrestricted internet access, as the root
cause.

The statement underscores that agentic AI deployments inherit the security
posture of whatever permissions and network access they're granted,
regardless of model behavior.
