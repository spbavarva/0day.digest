A vulnerability tracked as CVE-2026-15748 in a WordPress form plugin allows
unauthenticated attackers to upload arbitrary executable files, potentially
exposing up to 300,000 sites running the plugin. Arbitrary file upload
flaws like this typically lead to full site compromise if exploited.

Site owners running the affected plugin should update immediately and
check for unfamiliar files in upload directories.
