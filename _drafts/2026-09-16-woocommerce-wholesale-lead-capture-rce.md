Threat actors are actively exploiting a critical vulnerability in
WooCommerce Wholesale Lead Capture, a premium WordPress plugin with
more than 6,000 active installs, according to Wordfence. The flaw lets
unauthenticated attackers upload arbitrary files, including PHP
backdoors, to achieve remote code execution.

Wordfence said it has already blocked exploitation attempts. Site
owners running this plugin should update or remove it.
