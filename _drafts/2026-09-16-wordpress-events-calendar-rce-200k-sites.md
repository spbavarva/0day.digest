Vulnerabilities in The Events Calendar, a WordPress plugin used on more
than 200,000 sites, could give unauthenticated attackers remote code
execution capabilities.

Site operators running The Events Calendar should update to the patched
version as soon as it's available and review site activity for signs of
compromise.
