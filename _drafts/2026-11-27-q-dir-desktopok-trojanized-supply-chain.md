Researchers disclosed a software supply chain attack tampering with
installation files for Q-Dir and DesktopOK, two Windows utilities
distributed via the official SoftwareOK website. Malicious files were
generated both when users downloaded the tools directly and during the
update process for previously installed copies.

This means existing installations could have been silently compromised
via auto-update. Users of either tool should verify installation
integrity and check for indicators of compromise.
