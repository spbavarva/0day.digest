Ruby has patched a heap-based buffer overflow vulnerability, tracked as
CVE-2026-132825 and nicknamed Ruby2Shell, that could lead to remote code
execution.

Projects running affected Ruby versions should update as soon as
possible; no technical detail on exploitability in the wild has been
disclosed.
