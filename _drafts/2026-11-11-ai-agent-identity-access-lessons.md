Identity security vendor Token describes building an AI agent that
violated all three security principles it tells customers to follow for
agents: unique agent identities, access scoped to the task, and
traceability kept separate from any human user. The write-up uses the
exercise to reason through how browser-operating agents should be
defended when acting inside a user's authenticated session.

This is a practitioner lessons-learned piece rather than a disclosed
vulnerability or incident.
