Researchers found multiple Chrome and Edge extensions distributed through
official stores that delivered a malware framework capable of stealing
cryptocurrency, browser history, and other sensitive data.

The same framework also injected ClickFix-style lures, tricking users into
manually running malicious commands on their own machines.

Distribution through official extension stores let the campaign bypass the
trust checks users normally rely on before installing browser add-ons.
