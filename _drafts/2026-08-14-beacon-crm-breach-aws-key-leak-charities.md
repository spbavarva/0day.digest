A data breach at Beacon CRM has affected more than 1,000 charity
organizations that use the platform. The believed root cause is a
compromised AWS access key that was exposed in publicly available
JavaScript build artifacts.

The incident is a reminder to audit client-side build output for
accidentally embedded cloud credentials — a recurring root cause across
recent breaches.
