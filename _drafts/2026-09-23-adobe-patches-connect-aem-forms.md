Adobe patched nine critical security defects across Connect and AEM
Forms that could be exploited for arbitrary code execution and
privilege escalation. No active exploitation was reported in the
source summary.

Organizations running Adobe Connect or AEM Forms should apply the
September patches given the number of critical-severity issues
addressed.
