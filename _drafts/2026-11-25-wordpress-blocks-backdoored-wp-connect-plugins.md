Six WordPress plugins developed by WP Connect were backdoored on November
22, 2026, following a suspected compromise of the developer's account. The
backdoored code would have enabled arbitrary code execution on sites running
the plugins.

The WordPress plugins team proactively detected and blocked the malicious
releases before they went live, so sites that had the plugins installed were
not exposed. WP Connect users should still verify their installed versions
and watch for an official statement from the developer.
