Research from NMFTA found that a safety recall for the Bendix EC80 truck
brake controller also quietly patched remote code execution and
denial-of-service vulnerabilities. The recall was framed publicly as a
safety fix rather than a security update. The finding illustrates how
vulnerabilities in vehicle safety systems can be remediated without being
disclosed as security issues.
