Cloud application hosting platform Northflank disclosed a security breach
that allowed attackers to abuse AI API keys stored by customers on the
platform. Northflank is advising all customers to rotate every credential
and secret stored in their accounts, not just AI-related keys.

Practitioners using Northflank should rotate stored secrets immediately and
review API usage logs for anomalous activity tied to their AI provider
accounts.
