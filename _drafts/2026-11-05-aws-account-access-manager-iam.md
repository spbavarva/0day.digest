AWS has introduced account access manager, a new IAM capability that
combines existing IAM role flexibility with centralized federation through
AWS IAM Identity Center, adding user-level visibility into workforce access
across accounts.

The feature is aimed at simplifying how organizations manage and audit which
users can assume which roles across their AWS accounts. Teams already using
IAM Identity Center should evaluate whether this simplifies existing
entitlement reviews.
