Attackers distributed a malicious extension impersonating Claude Code
through Cursor's extension supply chain.

Once installed, the extension performed host reconnaissance and attempted
to open a reverse SSH tunnel back to attacker-controlled infrastructure.
The report did not specify how many users installed it before removal.
