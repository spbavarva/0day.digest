A malvertising campaign running on Bing is promoting a fake Claude
desktop app installer to deliver SectopRAT malware. The fake installer
is reported to be hosted on a legitimate Claude.ai domain, which could
make the lure harder for victims to spot as fraudulent.

Users should download the Claude desktop app only via links from
anthropic.com and verify installer sources before running them,
especially when arriving via search ads.
