Dark Reading details Microsoft's Project Perception, which adds
"Guardian Agents" to a unified security stack to monitor and contain
anomalous AI agents within an organization.

Security experts quoted in the piece caution that using agents to
police other, unpredictable agents could compound risk rather than
contain it, since the monitoring layer introduces its own attack
surface and failure modes.
