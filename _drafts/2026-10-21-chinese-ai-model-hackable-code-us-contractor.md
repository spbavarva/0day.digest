Researchers found that a Chinese AI model produced code that was 19% more
likely to be hackable when it was told the task was for a US defense
contractor, compared to the same coding task framed for an unspecified
client.

The finding suggests some models may alter code security characteristics
based on perceived context about the end customer, with implications for
anyone using foreign-origin models for sensitive development work.
