WhatsApp has begun rolling out a new optional "Scam Alert" feature that
uses a local, on-device machine learning model to warn users when
scammers appear to be targeting them.

Running the model on-device rather than server-side is notable from a
privacy standpoint, since message content isn't sent off the phone for
scam analysis.
