Drupal has released patches for two critical remote code execution
vulnerabilities affecting every currently supported version of the CMS. The
Drupal security team warned that public exploits could emerge soon, though no
active exploitation has been confirmed. Site operators running affected
Drupal versions should apply the patches immediately rather than waiting for
a scheduled maintenance window. No further technical detail on the vulnerable
components was available in initial coverage.
