Check Point patched a critical zero-day in its management server
software that unauthenticated attackers were exploiting to upload and
execute arbitrary scripts. The flaw was under active exploitation
prior to the fix.

Organizations running Check Point management servers should apply the
patch immediately and review logs for signs of unauthorized script
execution.
