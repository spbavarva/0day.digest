The Arch Linux project temporarily disabled adoption of orphaned Arch User
Repository (AUR) packages after a surge in malicious takeovers of existing
packages.

AUR package adoption lets users assume maintainership of abandoned
packages, a mechanism attackers have been exploiting to slip malware into
the repository. Arch Linux users should be cautious about AUR packages that
recently changed maintainers.
