Researchers at Forever Security showed that a malicious browser
extension able to run scripts on claude.ai could make Claude Desktop
run code on a person's computer. The attack relies on Dispatch, a
Claude feature that lets users send tasks from their phone to Claude
Desktop.

The researchers said the flaw enabling this could still be exploited
as of their report.
