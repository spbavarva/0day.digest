Microsoft's Project Perception introduces "Guardian Agents," designed to
monitor and contain anomalous behavior from other AI agents, as part of a
push toward a unified security stack.

The framing treats autonomous AI agents as a new insider-threat category
requiring dedicated controls. Security experts quoted in the piece warn
that using agents to police other unpredictable agents could multiply,
rather than contain, the risk, since the monitors inherit the same
unpredictability as what they're watching.
