Cybersecurity professionals are being targeted with infected security
projects hosted on GitHub that deploy a backdoor and information
stealer malware. The campaign specifically targets practitioners who
would be expected to download and run security tooling from GitHub as
part of their work.

Review any recently pulled security tooling from unfamiliar GitHub
repos before execution, and verify maintainer reputation and commit
history.
