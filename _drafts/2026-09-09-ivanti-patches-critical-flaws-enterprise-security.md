Ivanti patched six critical vulnerabilities in Neurons for ITSM that could
enable remote code execution, along with authentication bypass flaws in
Sentry and EPMM (Endpoint Manager Mobile). No active exploitation was noted
in the disclosure. Given Ivanti products' history as attacker targets,
customers running any of these three products should apply patches without
delay.
