1Password has disclosed a data breach after an employee's corporate GitHub
account was compromised. Attackers used that access to deploy malicious code
into the company's backend services.

The malicious code was then used to steal customer data.

This is a credential-compromise-to-backend-code-execution chain at a company
whose core product is a password manager, making the trust impact
significant. Affected customers should watch for official guidance from
1Password on credential rotation.
