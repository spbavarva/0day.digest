F5 released out-of-band patches addressing multiple vulnerabilities in
NGINX, including three rated critical that could allow attackers to execute
code on vulnerable systems.

Administrators running NGINX should apply the patches immediately given the
RCE potential. The advisory did not indicate active exploitation.
