Volexity attributed a spear-phishing campaign, tracked as UTA0560,
to a China-linked threat actor exploiting recently patched security
flaws in Google Chrome and Microsoft Windows to deliver a malicious
JavaScript backdoor called GRIMWEDGE.

The activity targeted multiple non-governmental organizations (NGOs)
starting September 1, 2026. The source summary did not specify the
CVE identifiers for the exploited flaws. Organizations that support
NGOs or operate in similar target profiles should ensure Chrome and
Windows are fully patched.
