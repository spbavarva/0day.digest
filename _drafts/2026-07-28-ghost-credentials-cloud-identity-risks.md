Security researcher Aleksandr Krasnov has released an open source tool for
identifying dormant non-human identities - service accounts, API keys, and
similar credentials - that create hidden trust paths into cloud
environments. This "identity sprawl" of unused or forgotten non-human
accounts is an increasingly common blind spot in cloud security posture.
The tool is aimed at helping teams surface and clean up these dormant trust
paths before they're abused. No specific incident or exploited case is
cited in the report.
