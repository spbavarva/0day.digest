Trail of Bits is using OpenAI's Codex to automate backporting of security
fixes into stable Linux releases, cutting the process from days to hours
per fix.

The project says it helped deliver fixes for 149 distinct CVEs into stable
Linux kernel releases by October 29, along with additional fixes to Fedora
and Ubuntu packages, easing work that's typically time-consuming and
thankless for maintainers.
