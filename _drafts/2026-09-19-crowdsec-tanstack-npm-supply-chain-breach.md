CrowdSec disclosed that an attacker copied roughly 170 of its private GitHub repositories in May, using the account of an employee who had just left the company but whose GitHub access remained open.

The employee's laptop had been compromised in the earlier supply chain attack on TanStack, in which malicious versions of TanStack's npm packages stole credentials from developer machines.
