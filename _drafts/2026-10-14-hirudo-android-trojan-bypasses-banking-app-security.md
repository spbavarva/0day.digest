Dutch mobile security firm ThreatFabric has disclosed a new Android banking
trojan called Hirudo that replaces legitimate banking apps with patched
versions built to disable in-app security checks.

ThreatFabric identified tampered replacements for at least eight Indonesian
banking apps, letting the malware intercept credentials and transactions
from inside what looks like the genuine app.

The technique is an escalation from typical overlay-based banking trojans,
since the malicious code runs inside a modified copy of the real app rather
than a fake one layered on top.
