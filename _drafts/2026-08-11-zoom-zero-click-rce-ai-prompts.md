Zoom has patched a zero-click code execution vulnerability, impacting the
annotation feature, that could let an attacker hijack another meeting
participant's device. Researchers at A Security say they found the flaw
using fewer than 20 prompts against publicly available AI models. The fix
is already out; Zoom users should ensure they're on the latest patched
client.
