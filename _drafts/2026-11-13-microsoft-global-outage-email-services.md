Microsoft is working to restore email and other services following a global
outage, using what the company described as "a measured approach to
identify and repair affected infrastructure." The root cause has not been
disclosed, and Microsoft has not said whether a security incident is
involved.

Organizations dependent on affected Microsoft services should monitor
Microsoft's status page for restoration updates and have contingency
communication channels ready.
