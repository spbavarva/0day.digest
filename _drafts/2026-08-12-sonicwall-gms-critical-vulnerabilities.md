SonicWall has patched critical vulnerabilities in its discontinued Global
Management System (GMS) platform. The flaws could let unauthenticated
attackers execute arbitrary code remotely and read sensitive data.

No active exploitation has been confirmed. Because GMS is discontinued,
organizations still running it should treat this as a signal to migrate
off the platform, not just patch in place.
