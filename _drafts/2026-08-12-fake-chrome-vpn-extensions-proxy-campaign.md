More than 737 browser extensions published on the Chrome Web Store
impersonated well-known VPN and proxy services while secretly routing users'
traffic through SOCKS5 proxies operated by a single provider. The scale of
the campaign suggests a coordinated effort to build a large proxy network
using unwitting users' bandwidth.

Users should verify VPN extension publishers carefully and prefer
established, audited providers over unfamiliar Chrome Web Store listings.
