Trail of Bits describes using AI agents for more than automated code
review: agents now let auditors build custom tooling and formal models
before a review even starts. As a case study, the firm used this approach
while reviewing Miden VM, a new zero-knowledge VM with its own custom
assembly language and almost no existing developer tooling.
