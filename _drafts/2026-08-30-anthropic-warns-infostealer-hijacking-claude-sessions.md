Anthropic is warning some Claude users that infostealer malware running on
their machines has stolen active Claude login sessions, letting attackers
access accounts and consume the victim's usage.

The technique lifts session data directly rather than passwords, so it can
bypass standard login and MFA checks — a pattern increasingly used against
SaaS and AI platform accounts.

Affected users should check for unfamiliar account activity and revoke
active sessions if compromise is suspected.
