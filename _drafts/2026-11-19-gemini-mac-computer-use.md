Google's Gemini app for macOS now has a computer-use feature that lets the
agent complete multi-step tasks across local files, desktop apps, and the
web — filling in forms, organizing files, and building presentations. The
capability mirrors similar agentic computer-use features rolling out
across the industry. Granting an AI agent direct control of a desktop
raises the same prompt-injection and permission-scoping concerns seen with
other computer-use agents; Google has not published technical detail on
sandboxing or guardrails for this release.
