Unit 42 reports that a Chinese-speaking threat actor, tracked under the
aliases knaithe and KnYuan, used the DeepSeek AI model through the
open-source Hermes Agent framework to run autonomous attacks against
internet-facing systems.

After an initial instruction issued via Telegram, the agent independently
found exposed systems, selected public exploits, and carried out attacks —
researchers recovered no further operator input during the session. The
case adds to a growing set of incidents where AI agents automate the
exploitation stage of an attack with minimal human involvement.
