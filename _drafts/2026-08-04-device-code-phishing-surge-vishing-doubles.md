Device code phishing incidents rose 1,500% in 2026, while voice
phishing (vishing) incidents doubled over the same period, according to
Dark Reading.

Both techniques help attackers bypass entrenched security controls such
as MFA while limiting the evidence they leave behind — the same trend
seen in today's Greatness PhaaS device code phishing update.
