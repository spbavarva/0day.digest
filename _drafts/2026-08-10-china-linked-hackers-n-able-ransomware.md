Microsoft said a China-linked threat actor is exploiting a critical
vulnerability in N-able's cybersecurity/remote-monitoring software to use it
as a launchpad for ransomware deployment, according to The Record. Turning
trusted security tooling into an attack vector increases the blast radius
for any organization using the affected N-able product. No CVE number,
patch status, or affected N-able product version was included in the
available summary. Organizations running N-able should check vendor
advisories for patches.
