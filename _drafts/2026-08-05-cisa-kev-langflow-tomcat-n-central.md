CISA added three flaws to its Known Exploited Vulnerabilities catalog
on August 5, 2026, citing evidence of active exploitation in the wild.

The headline entry is CVE-2026-9198 (CVSS 9.8), a code injection flaw
in Langflow that lets unauthenticated attackers achieve full remote
code execution. Flaws in Apache Tomcat and N-able N-central were also
added to the catalog.

Organizations running Langflow, Tomcat, or N-central should apply
available patches immediately given confirmed in-the-wild exploitation.
