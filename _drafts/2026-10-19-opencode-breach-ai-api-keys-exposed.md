An intruder accessed a legacy system at OpenCode on the night of October 16
and may have exposed third-party AI provider API keys that users had saved
in OpenCode Console, the company disclosed.

Console is OpenCode's optional hosted service that stores a workspace's
OpenAI, Anthropic, or Google API key so team members can use models without
configuring their own credentials. Affected users should rotate any API
keys stored in OpenCode Console.
