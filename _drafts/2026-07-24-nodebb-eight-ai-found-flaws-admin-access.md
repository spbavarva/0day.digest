Eight security flaws in NodeBB forum software went public on July 23
along with exploit code. Aikido Security rates all eight as high severity;
its AI pentest agents found them during a six-hour automated review of
NodeBB's source code. Every version before 4.14.0 is affected, including
flaws that expose admin access and private chats. NodeBB has patched all
eight issues — administrators should update to 4.14.2.
