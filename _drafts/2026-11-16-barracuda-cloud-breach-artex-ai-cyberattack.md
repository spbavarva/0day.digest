Hackers breached the cloud environment of network and email security
vendor Barracuda earlier this month using a stolen cloud access key
combined with ARTEX, an AI-powered penetration testing framework.

The incident is notable both for the initial access vector — a compromised
credential rather than a software vulnerability — and for the use of an
AI-driven offensive tool to accelerate post-compromise activity.
Organizations should audit cloud access key rotation and scoping
practices, since a single leaked key was reportedly sufficient for the
intrusion.
