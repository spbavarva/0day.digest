The Russian state-sponsored group Laundry Bear, also known as Void Blizzard, is exploiting a vulnerability in Microsoft Exchange Outlook Web Access (OWA) to maintain long-term mailbox access. The campaign delivers a custom backdoor called OWAReaper as part of ongoing email collection operations. No CVE identifier or patch guidance was included in current reporting. Organizations running Exchange OWA should monitor for anomalous authentication activity while more detail emerges.
