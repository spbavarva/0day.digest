CISA disclosed CVE-2026-19188, a maximum-severity (CVSS 10.0) OS command
injection vulnerability in Haiwell IoT Cloud HMI Gateway version 3.40.1.12.
Successful exploitation lets an attacker inject and execute arbitrary OS
commands with root privileges.

The gateway is deployed worldwide across energy, critical manufacturing,
and water/wastewater sectors, making this a high-priority patch for
industrial operators.
