Google is rolling out improved Chrome safeguards against ClickFix attacks for
users with Enhanced Protection enabled. ClickFix is a social engineering
technique that tricks users into copying and pasting malicious commands
directly into their operating system, bypassing conventional security
controls.

The new protections add warnings when a web page prompts a user to paste and
run a command.
