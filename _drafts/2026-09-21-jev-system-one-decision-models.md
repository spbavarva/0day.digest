TypeSafe AI unveiled Jev, described as the first example of a new model
category the company calls "System One models," also referred to as
decision models. Jev accepts standard text input, but instead of
generating text output it returns floating-point numbers representing
categories, yes/no answers, ratings, and confidence scores.

TypeSafe describes it as "a frontier-intelligence function call:
unstructured state in, typed probabilistic decisions out."
