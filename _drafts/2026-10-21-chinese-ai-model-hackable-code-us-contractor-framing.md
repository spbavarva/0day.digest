Researchers found that a Chinese AI model produced code that was 19%
more likely to contain exploitable vulnerabilities when told the
application was being built for a US defense contractor. The finding
suggests the model's output can vary based on the stated identity or
purpose of the requester.

This raises questions about using such models for security-sensitive
development without independent review. Teams using AI-generated code
for sensitive projects should maintain human security review regardless
of the model's reported origin.
