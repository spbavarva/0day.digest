AWS announced a partnership with Anthropic and OpenAI to bring "AWS
Continuum" into developer workflows, starting with a preview of AWS
Continuum for code vulnerabilities.

The tool combines foundation models from both labs with knowledge of a
customer's specific environment to identify code vulnerabilities. It's
currently in preview.
