CISA is warning of a new critical vulnerability in MikroTik RouterOS that
could allow an unauthenticated remote attacker to achieve code execution or
trigger a denial-of-service condition.

RouterOS runs on a large installed base of network and ISP-grade routers, so
unpatched, internet-facing devices are an attractive target. No active
exploitation was confirmed in this alert; admins should apply available
patches and restrict management-plane exposure regardless.
