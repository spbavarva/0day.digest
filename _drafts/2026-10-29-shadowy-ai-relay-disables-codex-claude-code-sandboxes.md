An unidentified relay service is reselling access to AI coding tools like
OpenAI Codex and Claude Code into mainland China and other regions where the
official products aren't sold — but with key security features, including
sandboxing, turned off.

The operators and scale of the service remain unclear, raising concerns
about unsanctioned, less-secure deployments of agentic coding tools outside
vendor-supported regions.
