Meta introduced Muse Code, a new coding agent for large codebases, alongside
Muse Spark 1.2, an update to its coding-focused model line.

Muse Spark 1.2 scales up training compute on coding tasks and expands
training environment diversity, with improvements to code generation,
complex debugging, and codebase understanding while maintaining strength in
other general capability areas.

The release continues a trend of labs prioritizing long-sequence agentic
tool calling as a key model capability.
