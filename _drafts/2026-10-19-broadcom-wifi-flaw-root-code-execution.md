Security researcher Quentin Kaiser disclosed an unpatched flaw in
Broadcom's Wi-Fi setup software that lets an attacker within radio range
execute code as root on Broadcom-based routers, without the network
password or any pairing step.

Kaiser demonstrated the attack against home gateways from three Belgian
internet providers, in one case reading the Wi-Fi password directly off the
device. No patch is currently available.
