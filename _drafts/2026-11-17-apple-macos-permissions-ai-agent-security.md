Apple introduced new macOS controls, currently previewed in macOS 27.3
beta 2, that give users more granular control over the data apps —
including AI agents — can access. The changes affect two existing
permission systems: Device Control and Data Access, and Full Disk Access,
adding more transparency and options before an app is granted broad
access.

The move is explicitly framed around the security risks posed by AI agents
operating with standing access to user data. Mac users and admins should
expect additional permission prompts as agentic AI apps request broader
data access under the new controls.
