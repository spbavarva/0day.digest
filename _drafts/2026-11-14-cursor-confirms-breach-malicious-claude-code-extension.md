Cursor confirmed it suffered a security breach that allowed attackers to
distribute a malicious Claude Code extension through its official
marketplace. The attackers reportedly gained the access needed for this by
stealing credentials from AI infrastructure provider Fireworks AI.

Users who installed extensions from the Cursor marketplace during the
affected window should treat the compromised extension as untrusted and
audit for unauthorized activity. Further technical detail on scope and
remediation was not available in the source report.
