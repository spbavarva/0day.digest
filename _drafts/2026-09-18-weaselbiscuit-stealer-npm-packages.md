Researchers found a cluster of 13 npm packages delivering a previously
undocumented JavaScript stealer codenamed WeaselBiscuit, which harvests
Chrome extension storage. Per OpenSourceMalware, the malware shows
functional overlap with malware strains tied to North Korea's Contagious
Interview campaign, including BeaverTail.
