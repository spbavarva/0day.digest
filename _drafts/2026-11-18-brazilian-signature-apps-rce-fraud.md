Government-sanctioned digital signature middleware used for legally
binding documents in Brazil contains remote code execution
vulnerabilities, according to Dark Reading.

The affected authentication middleware underpins exceptionally
important legal and financial documents, so successful exploitation
could enable both system compromise and document fraud.

Specific CVE identifiers and patch status were not detailed in initial
reporting. Organizations relying on these signature platforms should
watch for vendor advisories.
