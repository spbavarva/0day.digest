A critical vulnerability in Tencent's Chinese-language input method
editor for Windows allows remote code execution triggered by a single
click. Chinese state-linked hackers are actively exploiting the flaw.

The input method editor is widely deployed among Chinese-language
Windows users, giving the vulnerability a broad potential attack
surface. Affected organizations should prioritize patching and watch
for anomalous process execution tied to the IME component.
