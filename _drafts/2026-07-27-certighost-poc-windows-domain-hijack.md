A proof-of-concept exploit dubbed "Certighost" has been released targeting
a Windows Active Directory Certificate Services vulnerability. The exploit
allows an authenticated attacker to potentially compromise an entire
Windows domain. Organizations running AD CS should review certificate
template configurations and monitor for related indicators.
