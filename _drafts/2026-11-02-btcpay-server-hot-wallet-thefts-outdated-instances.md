The maintainer of BTCPay Server, an open-source cryptocurrency payment
processor, is warning that attackers are draining hot wallets on
instances running outdated versions. Administrators are urged to
update to the latest release immediately.

No specific CVE identifier was included in the available summary.
Self-hosted BTCPay operators should treat this as time-sensitive
patching guidance.
