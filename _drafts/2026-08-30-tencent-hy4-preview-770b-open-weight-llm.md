Tencent released Hy4 Preview, a new open-weight, text-only (no vision)
large language model. It has 770B total parameters with 49B active,
a 1M token context window, and is distributed as a 1.56TB download on
Hugging Face.

This is a large size increase over Tencent's previous model, Hy3,
released in July, which had 295B total parameters (21B active) and a
256,000 token context window.
