Researchers disclosed NoisyTCP, an 11-year-old Linux kernel vulnerability
affecting almost all Linux distributions. The flaw lets attackers crash
systems running Nginx, Apache, and SSH servers under default configurations.

Given its age and the breadth of affected distributions, this is a
significant denial-of-service exposure for Linux-based internet-facing
infrastructure.
