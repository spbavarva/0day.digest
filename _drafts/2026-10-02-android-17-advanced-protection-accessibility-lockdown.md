Google announced a new security measure that limits access to Android's
accessibility services to verified applications classified as
Accessibility Tools when Advanced Protection is enabled.

Malicious Android apps have used the accessibility API as a main
pathway for malware and financial fraud; Google says the change will
block that attack path.
