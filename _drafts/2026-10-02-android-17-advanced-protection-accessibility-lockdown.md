Google announced a new Android 17 security measure that restricts
accessibility services to apps classified as verified Accessibility Tools
when Advanced Protection mode is enabled.

Malicious Android apps commonly abuse the accessibility API as a primary
vector for malware and financial fraud; this change is intended to close
off that attack path for users who opt into Advanced Protection.
