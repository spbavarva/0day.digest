A critical Ruby on Rails vulnerability dubbed KindaRails2Shell is
reportedly being targeted by attackers. The arbitrary file read flaw
allows extraction of application secrets and can be leveraged for remote
code execution. No CVE identifier, affected version range, or patch
availability was specified in initial reporting. Rails operators should
monitor for indicators of exploitation and apply vendor guidance as it
becomes available.
