SAP confirmed a cybersecurity incident after detecting suspicious
activity on GitHub, according to SecurityWeek. Hackers reportedly used
stolen employee tokens to copy and alter source code in SAP's
development infrastructure.

The company has not confirmed the full scope of what was accessed or
whether customer-facing systems are affected. SAP's software is widely
deployed in enterprise environments, so any confirmed source code
exposure warrants close monitoring for follow-on supply chain risk.
