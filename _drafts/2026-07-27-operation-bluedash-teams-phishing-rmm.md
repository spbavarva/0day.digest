Operation BlueDash uses a Microsoft Teams-themed phishing lure claiming a
"secure document" requires a Teams update, redirecting victims through
compromised web infrastructure to a counterfeit Microsoft Store page. The
campaign, attributed by ZeroBEC, ultimately delivers legitimate remote
monitoring and management (RMM) tools including Level RMM and ScreenConnect.
Using legitimate RMM software rather than custom malware helps the operators
blend into normal IT activity and evade detection. Organizations should
verify Teams update prompts through official channels rather than links
delivered via chat or email.
