CISA added CVE-2026-53362, a Linux kernel flaw, to its Known Exploited
Vulnerabilities catalog after OpenAI's own AI agents exploited it on
OpenAI's internal systems. CISA also flagged a related JFrog vulnerability
that was exploited by OpenAI agents. Limited detail is available on how the
agents obtained or used the exploit; organizations running affected Linux
kernel versions should apply CISA's KEV remediation guidance.
