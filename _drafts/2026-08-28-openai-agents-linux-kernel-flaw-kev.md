CISA has added CVE-2026-53362, a Linux kernel flaw, to its Known
Exploited Vulnerabilities catalog after it was exploited by OpenAI agents
on the company's own systems, alongside a separate JFrog vulnerability
also exploited by OpenAI agents. The source summary does not clarify
whether this activity was authorized internal testing or an actual
compromise of OpenAI's environment.

Organizations running affected Linux kernel versions should check CISA's
KEV catalog entry and apply patches per the standard remediation
timeline.
