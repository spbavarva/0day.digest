WordPress.org is launching an automated security review for every
release of a plugin before it's distributed through the WordPress.org
update API, analyzing each update for potential security issues before
it reaches sites.

Previously, new plugins were reviewed before entering the directory,
but subsequent updates shipped without that same scrutiny, according
to WordPress Official Plugin Review team member David Perez. The
change closes a gap that has historically been used to slip malicious
code into trusted plugins via updates.
