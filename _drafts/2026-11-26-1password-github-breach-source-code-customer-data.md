1Password disclosed a security incident after an attacker compromised an
employee's GitHub account and used it to push malicious code and access
backend systems.

The attacker accessed some customer information and internal source
code, but 1Password says customer password vaults and other secrets were
not accessed.

The company says it took immediate steps to contain the incident once
discovered. Users should watch for 1Password's official guidance on
affected data and stay alert to phishing attempts referencing this
breach.
