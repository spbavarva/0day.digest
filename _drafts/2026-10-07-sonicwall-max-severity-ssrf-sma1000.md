SonicWall released hotfixes for a maximum-severity server-side request
forgery (SSRF) vulnerability affecting its SMA1000 series secure access
gateways.

No CVE identifier, exploitation status, or technical root cause was
included in the available summary.

Administrators running SMA1000 appliances should apply the hotfix as soon
as possible given the max-severity rating.
