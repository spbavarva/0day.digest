AWS announced Continuum, a new autonomous code security offering. The
announcement frames the tool around a growing problem: AI models are
uncovering more vulnerabilities and more sophisticated exploit paths than
existing security processes were built to triage, with each one requiring
investigation, reproduction, and a tested fix.

Further technical detail on Continuum's specific capabilities was not
included in the available summary.
