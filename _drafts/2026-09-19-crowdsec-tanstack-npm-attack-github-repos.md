An attacker copied roughly 170 of CrowdSec's private GitHub
repositories on May 22, using the account of an employee who had just
left the company. CrowdSec disclosed the incident on September 18.

CrowdSec had not revoked the departing employee's GitHub access. The
company says the employee's laptop was compromised in the earlier
supply chain attack on TanStack, in which malicious versions of
TanStack's npm packages stole credentials from developer machines.
