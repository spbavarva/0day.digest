Anthropic rolled out Claude Mythos 5.2 to selected partners and Fable 5.2
to general users, with improvements to coding and reasoning.
BleepingComputer's testing found notable cybersecurity-relevant changes
between the two: Fable 5.2 reportedly blocks fewer security-related tasks
than its predecessor, while Mythos 5.2 shows improved bug-finding
capability.

Security teams testing Claude models for defensive tooling, such as bug
hunting or code review, may see different capability and refusal behavior
depending on which tier they use.
