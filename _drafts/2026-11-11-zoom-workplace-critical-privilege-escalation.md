Zoom patched two security flaws in Zoom Workplace for Windows,
including CVE-2026-108186 (CVSS 9.6), an improper input validation bug
that could let an unauthenticated attacker escalate privileges on
affected systems. SecurityWeek separately reported Zoom shipped the fix
alongside unrelated Asus security patches.

No active exploitation has been reported. Zoom Workplace for Windows
users should update to the patched release.
