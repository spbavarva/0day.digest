The third post in Trail of Bits' Nitro Enclaves series examines the
integration between Nitro Enclaves and AWS KMS, where KMS verifies
attestation documents generated by an enclave so developers can offload key
management from their applications.

The post catalogs passive and active attack classes against the
enclave-KMS communication channel, noting that integrating any external
service — even one from the same cloud provider — introduces new threats
to an otherwise trusted enclave.
