A malicious cross-store browser extension named "Twitch Enhanced Viewer |
JeetBot" leaked OAuth tokens belonging to nearly 31,000 users. The
extension was distributed via both the Chrome Web Store and Firefox
Add-Ons under the developer name HISHIMIRO/jeetbot.cc.

Stolen tokens were forwarded to proxy servers operated by a Russian
commercial bot service.
