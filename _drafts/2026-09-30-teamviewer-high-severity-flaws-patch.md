Remote access software company TeamViewer warned customers to immediately
patch a set of high-severity vulnerabilities affecting its client and host
software.

The company's advisory did not include CVE identifiers or confirm active
exploitation. Organizations running TeamViewer client or host software
should apply the update as soon as possible.
