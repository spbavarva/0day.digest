Flashpoint researchers detail how a source code leak for BTMob, a mobile
remote access trojan, has expanded the malware's reach across cybercriminal
communities. The leak has given a broader set of threat actors access to
BTMob's capabilities, lowering the barrier to entry for mobile-targeted
intrusions.

Organizations managing mobile device fleets should expect wider distribution
of BTMob-derived tooling following the leak.
