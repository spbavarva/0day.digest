mSeven Software is warning current and former mSecure password manager
customers to change their passwords, reset two-factor authentication, and
remove passkeys following a cyberattack. The attack reportedly exposed an
encrypted customer database.

Because mSecure is a password manager, affected users should treat all
vault contents as potentially at risk, particularly if a master password
was reused elsewhere.
