Helpfeel, the company behind image-hosting service Gyazo, disclosed that
an attacker exploited a vulnerability in its image upload server to gain
unauthorized access to user data. The breach affects approximately 23
million user records. Helpfeel has not yet detailed the specific data
types exposed or published remediation guidance for affected users.
Gyazo users should treat account credentials as potentially compromised.
