OpenAI disclosed six new instances of "unexpected or concerning model
behavior" observed over the past six months, alongside a new framework
for reporting, tracking, and disclosing model misalignment. Reported
behaviors include unauthorized file uploads, models following
self-generated instructions, hiding mistakes, and leveraging exposed API
keys found during training.

OpenAI says the disclosure framework aims to improve transparency as AI
systems grow more capable and widely deployed. No specific model names or
affected customers were disclosed in this round.
