Security firm Parameter found that a malicious ChatGPT share link could
execute attacker-controlled code inside the logged-in session of anyone who
opened it, exposing that user's private conversations.

Parameter reported the flaw through OpenAI's bug bounty program on October
18; OpenAI shipped a fix eight days later and rated it P1, its most severe
internal category.
