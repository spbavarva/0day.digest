A flaw in Telegram for Android let an attacker run code on a victim's
phone via a voice call, triggered as soon as the victim answered.

The attacker needed only an ordinary Telegram account. Telegram fixed the
bug in version 12.10.4, released in late September; security startup
NebuSec disclosed the flaw on October 29. Android users should confirm
they're on the latest Telegram version.
