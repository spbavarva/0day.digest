An attacker exploited a remote code execution flaw in SGLang, an
open-source inference engine, to run code on one of NEAR AI's inference
servers. The breach, which occurred the prior Sunday, stole data from 18
agents and roughly 100 users. NEAR AI said the attacker could also have
observed requests processed on that server that day, including some sent
in a confidential mode meant to be isolated inside a trusted execution
environment. Organizations running SGLang should check for available
patches.
