Threat actors began exploiting a high-severity WordPress Core remote code
execution flaw almost immediately after a patch was released, according to
The Hacker News.

The vulnerability has no assigned CVE identifier yet but carries a CVSS
score of 8.1 and affects WordPress Core versions 4.7 through 7.1.3.

Researchers recorded nearly 63,000 exploitation attempts against the flaw
within 24 hours of the patch's release.

Site operators running WordPress Core in the affected version range
should update immediately rather than waiting for a routine maintenance
window.
