F5 released out-of-band security patches for multiple NGINX web server
flaws, including three rated critical that can let attackers execute code
on vulnerable systems. The emergency, out-of-cycle release signals high
urgency.

No active exploitation has been confirmed, but given NGINX's ubiquity as a
web server and reverse proxy, administrators should prioritize patching
internet-facing instances immediately.
