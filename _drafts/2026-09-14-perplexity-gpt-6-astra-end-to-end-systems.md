Perplexity is using OpenAI's GPT-6 Astra model to handle end-to-end
production tasks: writing communications, shipping software changes, and
monitoring live systems. OpenAI says Perplexity checks in on Astra's work
far less frequently than it did with earlier models.

The case study signals a shift toward less human-in-the-loop oversight for
agents with write access to production. No incident is reported, but reduced
checkpointing raises the stakes of any future agent misbehavior or prompt
injection against these systems.
