Researchers have attributed exploitation of CVE-2026-59310 (CVSS 9.8), a
directory-traversal vulnerability in Broadcom VMware vCenter Server that
allows arbitrary code execution, to a suspected China-nexus advanced
persistent threat group.

Following successful exploitation, the actor deploys ransomware derived from
the leaked Babuk source code. A patch for the vCenter flaw has already been
released; unpatched instances remain at risk.
